| Area | Tools and platforms |
| --- | --- |
| Cloud | AWS, EC2, VPC, Route53, S3, Lambda, ECS, EKS, RDS, CloudFront, SQS, SNS, DynamoDB, API Gateway |
| Kubernetes | EKS, Helm, Argo CD, Karpenter, Prometheus, Grafana, Docker, ECR |
| Automation | Terraform, AWS CDK, CloudFormation, Serverless Framework, Ansible, Golang, Bash, AWS SDK |
| Observability | OpenTelemetry, Prometheus, Grafana, Datadog, CloudWatch, New Relic, ELK, PagerDuty, Opsgenie |
| Delivery | GitHub Actions, GitLab Pipelines, CodePipeline, CodeBuild, CodeDeploy, Jenkins, CircleCI |

## Production patterns

* Multi-region AWS infrastructure.
* Kubernetes cluster operations and upgrades.
* CI/CD and GitOps delivery systems.
* Cost optimization, tagging, billing alerts, and backup policies.
* Security controls, least-privilege IAM, SSO, secrets, WAF, Shield, and network policies.
